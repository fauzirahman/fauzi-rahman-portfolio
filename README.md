## Engineering Approach

This portfolio is developed with an emphasis on practical software engineering rather than simply presenting static information.

The projects showcased here demonstrate several engineering principles:

### Modular Architecture

Applications are organized into logical modules and reusable components to improve maintainability and scalability.

### API-First Development

Backend services expose RESTful APIs that can be consumed by independent frontend applications.

### Separation of Concerns

Business logic, data access, API communication, and presentation are separated into appropriate application layers.

### Type Safety

TypeScript is used to reduce runtime errors and improve developer experience across frontend and backend applications.

### Observability

Health checks, synchronization monitoring, logging, and operational status are incorporated into enterprise-oriented projects.

### Production-Oriented Development

Projects are developed with deployment, configuration management, API reliability, and maintainability in mind.

## Local Development

Make sure the following tools are installed:

```bash
node --version

git --version
```

## Installation

Clone the repository:

```bash
git clone https://github.com/fauzirahman/fauzi-rahman-portfolio.git
```

Navigate into the project:

```bash
cd fauzi-rahman-portfolio
```

Install dependencies:

```bash
npm install
```

---

## Run Development Server

Start the development server:

```bash
npm run dev
```

Open the application in your browser:

```text
http://localhost:3000
```

The application uses the Next.js development server with automatic reload during development.

---

## Production Build

Create a production build:

```bash
npm run build
```

Start the production server:

```bash
npm start
```

---

## Code Quality

Run ESLint:

```bash
npm run lint
```

Before committing changes, it is recommended to verify:

```bash
npm run lint
npm run build
```

This helps ensure that the application passes static analysis and production compilation.
